# AI Resume Assistance

AI Resume Assistance is a full-stack web application that helps users create, improve, and analyze resumes using AI-powered suggestions and ATS (Applicant Tracking System) scoring.

## Features

- AI-powered resume analysis
- ATS score calculation
- Resume improvement suggestions
- Job description matching
- User-friendly interface
- Secure backend integration
- Responsive design

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- Framer Motion

### Backend
- Node.js
- Express.js
- MongoDB
- OpenAI API
- OpenRouter API

## Installation

### Clone Repository

```bash
git clone https://github.com/Siddhu70/Ai-Resume-Assistance.git
```

### Install Dependencies

Frontend:

```bash
cd frontend
npm install
```

Backend:

```bash
cd backend
npm install
```

## Environment Variables

Create a `.env` file inside the backend folder:

```env
OPENAI_API_KEY=your_api_key
OPENROUTER_API_KEY=your_api_key
MONGO_URI=your_mongodb_uri
PORT=5000
```

## Run Project

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
